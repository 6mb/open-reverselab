# open-reverselab Backup Control

This branch hosts the protected mirror workflow for `6mb/open-reverselab`.

- Upstream: `LING71671/open-reverselab`

- Release mirror: newest 5 releases only, including assets when releases exist
- Delete protection: the job stops before pushing if upstream looks unavailable,
  empty, or unexpectedly incomplete.
